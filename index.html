Shared Live Database (Google Firebase - 100% Free)

Device Storage

Connect a free Google Firebase database so the Owner & Manager always see the exact same live members and revenue in real-time on both their mobile phones and PCs.

Quick 2-Minute Setup (100% Free Forever, No Credit Card):
  1. Go to console.firebase.google.com and sign in with any Google account.
  2. Click "Add project" → Name it gk-fitness-gym → Click Continue.
  3. In the left menu, click "Build" → "Firestore Database" → "Create Database" (select Start in test mode).
  4. Click the Project Settings Gear Icon (⚙️) → General → Scroll down to "Your apps" → Click the Web icon (</>).
  5. Copy the firebaseConfig = { ... } snippet and paste it below, then click "Connect Live Shared Database"!
